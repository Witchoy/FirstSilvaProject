# Walking Game (Pirate Theme)

Small pirate-themed walking game built in Unreal Engine 5.7.

## Team
- Jules Goy — Developer
- Vincent Marzin — 3D Artist

## Studio
- Silva

## Setup
- Clone the repo.
- Open `UE_project/UE_project.uproject` right-click and choose "Generate Visual Studio project files".
- Open the generated solution, build, then launch from the editor (or right-click the `.uproject` and choose Launch).
